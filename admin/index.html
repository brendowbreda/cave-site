Como criar a chave de acesso (uma vez só)
  1. No GitHub, abra Settings → Developer settings → Personal access tokens → Fine-grained tokens e toque em Generate new token.
  2. Dê um nome (ex.: Admin Cave) e escolha a validade.
  3. Em Repository access, escolha Only select repositories e marque cave-site.
  4. Em Permissions → Repository permissions, coloque Contents em Read and write.
  5. Toque em Generate token, copie a chave e cole acima. Guarde em lugar seguro.
